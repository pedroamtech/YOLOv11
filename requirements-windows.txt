#   1) Install PyTorch FIRST, from the CUDA wheel index (command below, NOT from this file).
#   2) Then install this file. If you `pip install -r` this file before step 1, pip may resolve
#      a CPU-only torch build from PyPI and step 1's CUDA build would need to be reinstalled.
#
# ---------------------------------------------------------------------------------------------
# STEP 1 — PyTorch with CUDA support for an RTX 5060 Ti (Blackwell, compute capability sm_120)
# ---------------------------------------------------------------------------------------------
# NOTE ON THE REQUESTED "cu124" INDEX: cu124 wheels predate Blackwell (RTX 50-series) GPU kernel
# support and will raise "CUDA error: no kernel image is available for execution on the device"
# on an RTX 5060 Ti even though torch.cuda.is_available() returns True. The NVIDIA driver's
# "CUDA Toolkit 13.3" capability is backward compatible with older PyTorch CUDA runtimes, so you
# do NOT need a cu13x wheel index to exist — you need a wheel that ships sm_120 kernels, which is
# cu128 (or newer) starting with PyTorch 2.7. Use:
#
#   pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
#
# If you specifically need the cu124 index for another reason, add sm_120 support is NOT present
# there — do not use it for this GPU.
#
# ---------------------------------------------------------------------------------------------
# STEP 2 — install this file
# ---------------------------------------------------------------------------------------------
#   pip install -r requirements-windows.txt
#
